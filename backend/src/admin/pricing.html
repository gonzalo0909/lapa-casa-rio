Comisión por pago con tarjeta

Stripe cobra una comisión real por cada pago con tarjeta (PIX vía Mercado Pago no tiene este costo). Este porcentaje se suma al monto que paga el huésped cuando elige tarjeta, para que la comisión no salga de tu bolsillo. Ajustalo si Stripe cambia sus tarifas.

⚡ Descuento PIX

Porcentaje de descuento aplicado al depósito cuando el huésped elige pagar con PIX. El banner promocional "Oferta especial — 10% con PIX" se muestra automáticamente en el paso de resumen de la reserva. Ponelo en 0 para desactivar el descuento y ocultar el banner.
