Doble verificación (2FA)

Además de la contraseña, pide un código de 6 dígitos generado por una app como Google Authenticator o Authy. Opcional -- si no la activás, el login sigue funcionando exactamente igual que hoy.

Activar

  1. Escaneá este código QR con tu app autenticadora (o ingresá la clave manualmente).
  2. Escribí el código de 6 dígitos que te muestra la app para confirmar.
Guardá este código de respaldo en un lugar seguro.

Sirve para entrar si perdés el celular con la app. Solo se muestra esta vez.
